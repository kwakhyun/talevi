## 실시간 처리와 기록 재생의 구분

**대사와 모델이 추출한 상태는 2026-10-10의 실제 모델 평가 기록을 재생합니다.** 새 모델 호출이 OpenAI 조직의 설정된 지출 한도에 막혔고, 사용자의 동의를 받아 이 방식으로 완성했습니다. 지출 한도나 결제 설정은 변경하지 않았습니다.

촬영에 사용하는 별도 API 어댑터는 `haru:long_01`부터 `haru:long_04`까지의 입력과 `text`, `reply_state`만 그대로 읽습니다. 출처는 [`extended.jsonl`](../evidence/cast-v11-2026-10-10/extended.jsonl)이며 원본 파일 SHA-256은 `643127becfe3646212542ea23eebc55d1dc52bb58fb0f160646c8eb0c6cedf9d`입니다. 기록된 모델은 `gpt-6-sol`입니다. 입력과 출력, 상태의 해시를 검사하며, 등록되지 않은 입력에는 새 응답을 만들지 않습니다.

- **기록 재생:** 모델의 대사와 상태 제안. 4글자당 30ms로 나누는 표시 속도는 시연 설정이며 실제 모델 지연이나 최신 모델 성능의 측정값이 아닙니다.
- **현재 앱에서 실제 처리:** 요청 접수, 작업 선점, 저장된 SSE 이벤트 전달, 크레딧 원장, 상태 근거 검사, 기억 수정과 잠금, 관계와 이야기 갱신, 체크포인트 복원과 원본 보존.
- **고정된 대본:** 모델 응답은 과거 합성 평가의 네 턴입니다. 현재 앱의 기억을 수정한 뒤 모델이 새로 답변한 장면으로 해석하면 안 됩니다.
- **별도 촬영 환경:** 개인 대화가 없는 전용 DB를 사용했습니다. 서비스 소스는 바꾸지 않았고, 웹 복사본의 안내 문구만 “기존 실제 응답 재생 중”으로 바꿨습니다.
- **호출 차단:** 재생 중 API 키를 비우고 OpenAI 클라이언트, HTTP 전송과 Python 소켓의 외부 연결을 막았습니다. DB 연결만 로컬 전용 포트로 허용합니다.

촬영 준비 중에는 새 대화 요청 1건에서 기본 모델과 대체 모델의 SDK 재시도를 포함한 4회의 생성 시도가 거절됐습니다. 원인 확인용 최소 요청 1회도 같은 한도로 거절됐습니다. 성공적으로 완료된 새 모델 생성은 없으며 재생 단계의 유료 모델 호출은 0회입니다. 이 사실은 공급자의 최종 청구액을 감사했다는 뜻은 아닙니다. 실패한 대화의 앱 크레딧 환급도 확인했습니다.

## 촬영하면서 확인한 상태

첫 답변 이후에는 `이름=하람`, `좋아하는 음료=유자차`가 저장됩니다. 다음 세 턴에서 약속을 추가하고 시간을 수정한 뒤, 함께 점검하자는 선택으로 신뢰와 협력 기록이 생깁니다. 이름을 `가을`로 직접 고친 상태에서 첫 답변으로 분기하면 다음과 같이 돌아옵니다.

| 상태 | 분기 직전 원본 | 첫 답변에서 만든 새 갈래 |
| --- | --- | --- |
| 이름 | 가을, 수동 잠금 | 하람, 자동 기억 |
| 좋아하는 음료 | 유자차 | 유자차 |
| 약속 | 수정한 시간, 장소와 준비물 | 아직 없음 |
| 신뢰 / 협력 | 1 / 1 | 0 / 0 |
| 이야기 | 게임기 점검 목표 | 첫 대화 시점의 상태 |
| 원본 대화 | 유지 | 별도 대화로 생성 |

화면 확인에 더해 전용 DB에서 원본과 새 갈래, 선택한 체크포인트를 읽기 전용으로 비교했습니다. [시연 상태 검증 결과](state-verification.json)

## 재현과 제작

현재 API 구현 기준은 `2f512767a1461d58d8cf84675df8a254a7aecc33`입니다. [재생 전용 어댑터](../../scripts/replay_demo_api.py)는 운영 실행 경로에 연결하지 않았습니다. 먼저 전용 로컬 DB `yeoun_video_20261015`를 만들고 현재 마이그레이션을 적용해야 하며, 기존 사용자 DB에 연결해서는 안 됩니다. API는 `127.0.0.1:8003`, 웹 복사본은 `127.0.0.1:3002`를 사용합니다.

```sh
# DB나 모델 호출 없이 기록 무결성과 호출 차단만 검사
.venv/bin/python scripts/replay_demo_api.py --check

# 이미 마이그레이션한 전용 DB로 시연 API 실행
.venv/bin/python scripts/replay_demo_api.py
```

화면은 브라우저에서 직접 조작하며 캡처한 연속 프레임입니다. 프레임 시각을 보존해 클립으로 만들고, 장면별로 편집했습니다. 입력 준비와 장면 사이의 대기 시간은 생략했고, 영상의 정지 화면은 설명을 위한 화면 유지입니다. 합성 내레이션은 설치된 macOS Yuna 음성을 사용했으며 사람의 녹음이 아닙니다. 외부 음성 생성 서비스와 배경 음악은 사용하지 않았습니다.

[렌더러와 입력 형식](rendering.md)은 PNG/MP4와 음성으로 1080p 영상을 만듭니다. 촬영 원본 프레임과 음성, 편집 manifest는 로컬 `.local/video-capture/`에 보존하며 저장소에는 최종 영상, 자막, 대본과 검증 결과를 포함합니다. [최종 미디어 검수](media-verification.json)

이 영상은 데스크톱 웹 시연입니다. 모바일 실기기, 실결제, 공개 호스팅, 장기간 운영 부하나 상용 서비스와의 동일 조건 품질 비교를 시연한 자료는 아닙니다. 채용 검토자는 영상으로 동작을 확인한 뒤 [기술 설명](../portfolio/ENGINEERING.md)과 [검증 결과](../portfolio/LATEST-VALIDATION.md)에서 구현과 한계를 함께 볼 수 있습니다.
