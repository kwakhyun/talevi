# 시연 영상 대본

길이: 2분 43초. 음성: macOS Yuna의 합성 내레이션. 응답은 기록 재생이며, 기억 편집과 분기는 현재 앱에서 처리합니다.

## 00:00:00 — 기억이 쌓이고, 이야기가 이어지는 대화

테일비는 캐릭터와의 대화를, 기억과 관계가 이어지는 이야기로 만드는 서비스입니다.

지금부터 로컬 앱에서 핵심 기능을 보여드리겠습니다.

## 00:00:11 — 서로 다른 출발점을 가진 30명의 캐릭터

서른 명의 성인 캐릭터를 성별과 장르, 그림 스타일로 탐색합니다.

캐릭터마다 말투와 성격, 첫 만남의 상황이 다릅니다.

게임 가게를 지키는 하루를 선택하고, 첫 대화를 시작해 보겠습니다.

## 00:00:27 — 기록 재생 | 캐릭터의 말투와 상황을 이어가는 응답

이 영상의 대사와 상태 추출 결과는, 십월 십일 실제 모델 검증 기록을 재생한 것입니다.

새 모델 호출은 조직 지출 한도로 막혀 있습니다. 화면에 보이는 재생 속도는 실제 모델의 응답 속도가 아닙니다.

이름과 좋아하는 음료, 약속을 말하면 대화와 함께 기억 노트에도 반영됩니다.

## 00:00:49 — 기록 재생 | 사용자가 직접 고치고 잠글 수 있는 기억

기억은 숨겨진 프롬프트에만 남지 않습니다. 사용자가 직접 확인하고 수정할 수 있습니다.

이름을 가을로 바꾸고 기억을 잠가 보겠습니다.

지금 하는 기억 수정과 저장은, 현재 앱과 데이터베이스에서 실제로 처리됩니다. 잘못된 기억은 삭제할 수도 있습니다.

## 00:01:09 — 기록 재생 | 함께 한 행동이 관계와 이야기의 상태로

관계는 대화 횟수만으로 일괄 상승하지 않습니다. 협력이나 갈등 같은 사건을 근거로 변화합니다.

하루의 일을 함께 살펴보자는 선택이, 관계의 변화와 게임기 점검이라는 목표로 이어졌습니다.

이렇게 남긴 상태는 다음 대화의 문맥에 다시 사용됩니다.

## 00:01:29 — 기록 재생 | 선택한 순간으로 기억과 관계를 함께 복원

이제 이전 답변에서 새로운 이야기로 분기해 보겠습니다.

분기에는 대사만 복사하지 않습니다. 선택한 턴의 기억과 잠금 여부, 관계, 이야기 상태를 함께 복원합니다.

이름은 수정 전의 하람으로 돌아오고, 이후에 생긴 약속과 관계 변화도 이 분기에 섞이지 않습니다.

원래 대화는 그대로 남습니다. 답변 재생성과 메시지 수정도 같은 체크포인트 구조를 사용합니다.

## 00:01:57 — 화면부터 작업 큐와 데이터베이스까지

웹과 모바일은 같은 API를 사용합니다. 대화 작업은 데이터베이스에 먼저 기록하고 작업자가 처리합니다.

현재 답변은 완성 후 품질 검사를 거쳐, 이벤트 스트림으로 전달합니다.

요청이 중복돼도 중복 차감을 막고, 생성에 실패하면 사용한 재화를 돌려줍니다.

## 00:02:19 — 144개 자동 검증 통과, 한계까지 공개

최신 검증에서는 API 백일곱 개, 웹 열한 개, 모바일 스물여섯 개, 모두 백마흔네 개가 통과했습니다.

웹 빌드와 모바일 내보내기, 빈 데이터베이스의 마이그레이션도 확인했습니다.

상용 서비스보다 우수하다는 결론은 아직 내리지 않았습니다. 실제 모델 평가와 자동 테스트의 범위를 나눠 문서에 정리했습니다.
