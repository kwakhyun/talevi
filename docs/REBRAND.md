# 테일비 Talevi: 이름, 화면, 캐릭터 개편

2026-10-08. 한국어 우선 서비스이며 공개 배포는 보류한 상태다.

## 이름을 고른 기준

**테일비 / Talevi**를 사용한다. 발음 가이드는 ‘테일-비’, 영어로는 ‘tale-vee’다. 영문 6자이고 한국어로도 같은 이름을 부를 수 있다. 이야기라는 뜻의 *tale*과 생생함을 연상시키는 *vivid*에서 착안한 조어다. 특정 성별이나 연애 장르를 이름에 가두지 않아 일상, 로맨스, 판타지로 확장하기 좋다.

- 한국어와 영어의 발음 연결: ‘여운’을 로마자로 옮길 때 생기는 읽기 어려움을 줄인다.
- 기억과 입력: 짧은 영문 표기, 받침 없는 한국어 끝음절, 검색창에 옮기기 쉬운 철자를 우선했다.
- 서비스 적합성: 캐릭터와 함께 이야기를 만든다는 기능을 이름에서 연상할 수 있다.
- 확장성: 특정 성별, 그림체, 한국적 정서에만 기대지 않는다.

| 검토 후보 | 판단 |
| --- | --- |
| 테일비 / Talevi | 채택. 짧은 발음과 이야기 연상이 모두 가능하다. 이탈리아 성씨로도 사용되는 표기이므로 완전히 새로운 단어라고 주장하지 않는다. |
| 미로아 / Miroa | 제외. 이미 같은 이름의 [영상 일기 앱](https://apps.apple.com/us/app/miroa-private-video-journal/id6775486360)이 확인됐다. |
| 로벨 / Rovelle | 제외. 한국어 이름이 기존 [AI 캐릭터챗 로벨](https://www.rovel.ai/)과 겹친다. 영문 이름의 [요리 앱](https://rovelle.app/)도 확인됐다. |
| 베일로 / Veylo | 제외. 이미 [AI 기반 CRM](https://veylo.to/) 등 여러 디지털 서비스가 사용하고 있다. |

일반 웹 검색으로 이름 충돌을 1차 확인했다. Talevi의 도메인 등록 가능 여부와 상표 등록 가능성을 확인한 것은 아니며, 등록이나 구매는 진행하지 않았다.

제품 문구는 **‘취향이 되는 첫 대화’**, 보조 문구는 **‘상상보다 가까운 이야기’**로 정했다. 화면의 영문 로고는 `talevi.`이며 한국어 서비스 표기는 ‘테일비’다.

## 공개 화면에서 가져온 설계 원칙

아래 내용은 실제 공개 화면과 브라우저에서 확인한 시각적 구조다. 원본 이미지, 로고, 문구와 소스 코드는 복제하지 않았다.

| 레퍼런스 | 관찰한 강점 | 테일비 적용 |

| [제타](https://zeta-ai.io/ko) | 어두운 배경 위 이미지 중심의 캐릭터 카드, 짧은 소개와 태그, 모바일 하단 탐색 | 모바일 2열 표지, 첫 문장 중심 소개, 하단 5개 메뉴, 상세에서 시작 문장 제공 |

| [위프](https://www.whif.io/) | 어두운 보라 계열 분위기, 검색과 취향 설정의 높은 접근성, 그림 중심 추천 | 코랄 포인트와 플럼 채팅 말풍선, 성별과 그림체의 독립 필터, 장르 칩 |

제타는 신규 방문 동의 안내, 위프는 취향 선택 안내가 표시된 상태에서 공개 배경 화면까지 확인했다. 계정 생성이나 약관 동의는 진행하지 않았다. 베이비챗은 프로모션과 취향 안내를 닫은 공개 메인 화면을 확인했다.

색상은 배경 `#111216`, 패널 `#1b1d24`, 강조 `#ff6b85`로 통일했다. 장식적인 긴 문구와 세리프 타이포그래피를 줄이고, 실제 얼굴과 첫 만남의 상황을 먼저 보여준다. 캐릭터 수는 실제 목록에서 계산하며, 가상의 인기 순위나 이용자 수를 표시하지 않는다.

모든 필터는 조합해서 사용할 수 있다. 예를 들어 ‘남성 + 애니메이션’은 강시온, 서지한, 카이렌 3명을 보여준다. 개인 제작 캐릭터도 그림체를 지정할 수 있다.

## 반영 범위와 이전 데이터

- 웹의 로고, 메타데이터, 탐색, 검색, 추천, 카드, 상세, 채팅, 기억 패널, 계정과 결제 화면을 개편했다.
- React Native 앱에도 새 이름, 색상, 10개 이미지, 성별/그림체 필터와 그림체 배지를 반영했다.
- API가 새 오리지널 카탈로그를 정해진 순서로 제공하고 재실행 시 설정을 갱신한다.
- 기존 4개 캐릭터는 비공개로 내리고, 그 캐릭터의 대화 목록 노출과 새 대화를 막았다. 기존 기록을 임의로 소실시키지 않도록 DB에는 보존한다. 원본 이미지는 공개 경로에서 제거해 `.local/retired-character-art/`에 옮겼다.
- 패키지 이름, DB 이름과 기존 인증 키의 내부 `yeoun` 식별자는 호환성을 위해 유지한다. 화면에 표시하는 브랜드는 테일비다. 기존 Vercel 프로젝트에는 변경을 배포하지 않았다.
