# 무료 배포 구성과 포트폴리오 판단

검토일: 2026-10-15. 구성 코드는 준비했으며 공개 배포는 실행하지 않았다. 계정 연결 단계에서 사용자가 로컬 녹화본과 공개 배포의 포트폴리오 가치를 재검토하도록 요청했다.

## 권고

현재 목적에는 **로컬 시연 영상 + 공개 소개 저장소 + 기술 설계와 검증 근거**를 우선한다. 공개 체험 서버는 채용 담당자가 직접 조작할 필요가 생겼을 때 추가한다. 영상만으로 내부 구현과 재현성을 설명하기는 부족하므로 기억 수정, 관계 변화, 분기 복원, 연결 복구의 화면과 그 구현 근거를 함께 제공한다.

실제 모델로 대화했던 기존 평가 기록은 모델 품질 근거로, 외부 HTTP를 차단한 자동 테스트는 상태 정합성 근거로 구분한다. 고정 응답을 재생한 영상은 재생임을 표시한다. 로컬 시연을 공개 운영 이력으로 표현하지 않는다.

추천 시연 구성은 2~3분이다. 캐릭터 선택과 대화(30초), 기억 수정과 관계 근거(45초), 재생성/편집/이야기 분기의 상태 복원(45초), 연결 복구와 테스트/구조 설명(30초)을 보여준다. 새 유료 호출 없이 이미 저장된 합성 대화와 무료 분기 기능으로 주요 흐름을 설명할 수 있다. 면접에서는 필요하면 로컬 화면 공유로 보완한다.

## 준비한 구성

| 영역 | 선택 | 비용 제한 조건 |
| --- | --- | --- |
| 웹 | Vercel Hobby, 기존 `khyun/yeoun` 프로젝트 | Hobby 유지, Pro 체험/유료 부가 기능 미사용. 개인 비상업 포트폴리오 용도 |
| API | Render Free 웹 서비스 1개, 싱가포르 | 워크스페이스 Hobby, 카드 미등록 유지. 별도 워커/디스크/Render DB 생성 안 함 |
| DB | Neon Free PostgreSQL | Free 유지, 카드 및 유료 플랜 미등록. 사용량 초과 시 업그레이드하지 않음 |
| AI | 기존 OpenAI 모델과 키 | 호스팅과 별도 과금. 공개 방문자가 실제 대화를 하면 모델 비용 발생 |

Vercel Hobby 및 Render Hobby/카드 미등록을 계정에서 확인했다. Render 서비스는 0개이며 Neon 계정과 DB는 아직 연결하지 않았다. `render.yaml`은 Render 공식 Blueprint 검증에서 유효 판정을 받았다. 요금제를 선택하는 설정 파일만으로 계정의 결제 정책 전체가 고정되지는 않으므로 실제 배포 직전에 다시 확인한다.

## 무료 환경에 맞춘 코드

- API 안에 대화 워커를 통합한다. 단일 uvicorn 프로세스로 실행하고, 새 요청 커밋 뒤에 이벤트로 깨운다. 작업이 없으면 DB를 조회하지 않는다.
- 시작할 때 DB에 남은 대기 작업을 확인한다. 이미 생성 중이던 작업은 재호출하지 않으며, 기존 임대 시간이 만료되면 정확히 한 번 환급한다. 미완료 작업이 있을 때만 회수 타이머를 유지한다.
- `/health`는 DB를 조회하지 않는 생존 확인이다. Render health check는 이 경로를 쓴다. DB를 확인하는 `/ready`는 배포 진단에만 사용하며 주기적 호출 대상으로 설정하지 않는다.
- 무료 환경에서 지원하지 않는 pre-deploy hook 대신 시작 명령에서 Alembic을 실행한다. `DATABASE_URL`은 TLS를 사용하는 Neon 직접 연결 주소여야 한다. 세션 advisory lock을 쓰므로 `-pooler` 주소를 사용하지 않는다.
- 웹은 첫 접속 때 읽기 전용 `/health`를 최대 90초 동안 기다린다. 결제나 메시지 생성 POST를 자동 재전송하지 않는다. 진행 안내와 수동 재시도 버튼을 제공한다.
- `WEB_ORIGIN`은 실제 Vercel 공개 주소, Vercel의 `API_INTERNAL_URL`은 실제 Render HTTPS 주소로 설정한다. 비밀 값은 저장소에 넣지 않는다.

## 한계와 검증 범위

Render Free는 15분간 유입이 없으면 중지되며 다음 접속 시 약 1분이 걸릴 수 있다. 월 750시간을 초과하면 중지된다. 카드가 없으면 대역폭 초과 시 무료 서비스가 중지되고, 빌드 시간 초과 시 새 빌드가 중지된다. Neon Free는 5분 미사용 시 compute를 중지하며 저장공간, compute, 전송량의 제한이 있다. 상시 가용성을 보장하는 운영 환경으로 설명하지 않는다.

외부 HTTP를 차단한 API 테스트 107개, 웹 SSE/초기 연결 테스트 11개를 통과했다. 대기 중 DB 조회 중단, 동시 신호 유실 방지, 재시작 후 대기 작업 처리, 생성 중 작업의 재호출 방지/환급, 재생성 작업 깨우기를 포함한다. 타입 검사와 Next.js 프로덕션 빌드도 통과했다. 이번 변경의 유료 AI 검증 호출은 0회다. 실제 클라우드 연결, SSE 프록시, 배포 재시작은 아직 검증하지 않았다.
