# v10 중간 검증 보존본

기본 240회, 후속 916회, 관계 단계 비교 60회, 실제 HTTP 8회, 회귀 14회를 모두 완료했다. 이 폴더를 최종 품질 통과 자료로 사용하지 않는다.

30턴 마지막 답에 기억 값이 모두 등장하더라도, 리나는 처음부터 허구의 약속에 참석할 수 없다고 답했고 소율은 실제로 방문할 수 없다는 설명을 반복했다. 엘리세와 도건은 각 세계관의 정원 관리와 폭설을 이유로 조건을 붙였으므로 이들의 제약을 단순한 기억 소실로 분류하지 않는다. 문자 회상 검사만으로 몰입과 합의의 정확성을 판정할 수 없다는 사례다.

또한 첫 만남/깊은 신뢰의 통제된 비교에서 대사 차이가 작은 캐릭터가 많았다. v11에서는 역할극의 일반적인 약속과 현실의 직접 만남 요청을 구분하는 규칙, 30명 각각의 관계 단계별 연기를 추가했다.

최신 검증은 인접한 `cast-v11-2026-10-10` 폴더에 별도로 보관한다. 실패와 중간 결과를 덮어쓰지 않는다.
