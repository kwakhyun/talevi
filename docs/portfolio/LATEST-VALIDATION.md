## 핵심 기능에서 확인한 것

- **30명 전체:** 미래 상태를 만든 뒤 과거 장면에서 분기, 재생성, 편집했을 때 모델에 전달할 문맥이 당시 상태와 일치하는지 확인했습니다. 이후 기억과 이야기의 혼입, 근거 메시지 ID의 잘못된 연결, 원본 대화 변경을 검사했습니다.
- **정확한 복원:** 기억 잠금과 삭제 표시, 관계, 이야기, 설정, 문맥 가림과 메시지 순서를 복원합니다. 중첩 분기, 같은 시간의 메시지, 나중에 과거 날짜로 넣은 메시지, 이전 v1 체크포인트도 검사했습니다.
- **중복과 실패:** 같은 요청의 재전송, 요청 번호 충돌, 잔액 부족, 체크포인트 저장 실패와 환급 시나리오를 검사했습니다.
- **기억과 관계:** 이름 변경 후 같은 문장의 약속 보존, 기억 잠금, 사실 근거 확인, 의미 없는 입력과 관계 점수 조작 요청, 반복 발언에 대한 처리를 검사했습니다.
- **워커 대기와 재시작:** 작업이 없을 때 DB 조회가 멈추고 새 요청 때 다시 처리하는지, 빈 큐 조회 중 신호가 유실되지 않는지 확인했습니다. 재시작 후 대기 작업은 처리하고, 이미 생성 중이던 작업은 재호출하지 않고 만료 후 환급하는 것도 검사했습니다.
- **건강 확인:** `/health`가 DB 접속 없이 응답하는지 검사했습니다. 실제 Neon의 휴면 전환을 관측한 결과는 아닙니다.

## 유료 모델 호출과 분리

**이번 자동 검증의 유료 AI 호출은 0회입니다.** API 시험은 `DEMO_MODE=true`, `RUN_WORKER=false`, 빈 API 키를 강제합니다. 기본 동기 및 비동기 HTTP 전송 계층을 차단하여, 모의 응답 없이 외부 요청을 시도하면 검사가 실패합니다. 시험 대상은 실제 PostgreSQL 트랜잭션과 API 흐름이며, 모델 답변은 고정된 응답이나 모의 클라이언트로 대체했습니다.

따라서 이번 결과는 상태 복원과 오류 처리의 근거입니다. 캐릭터의 말투, 창의성, 이용자 만족도나 최신 모델 품질을 새로 평가한 결과가 아닙니다. 별도로 제작하는 시연 영상의 실제 모델 호출은 이 자동 검사 수와 호출 수에 포함하지 않습니다.

## 실행 환경과 재현

로컬 macOS에서 Node.js 22.21.0, npm 10.9.4, Python 3.11.4, PostgreSQL 18.4를 사용했습니다. CI 설정의 Python 3.12와 PostgreSQL 17은 별도 환경이며 이번 로컬 결과를 해당 환경의 새 CI 실행 결과로 표현하지 않습니다.

API 검사는 운영/시연 DB 대신 전용 `yeoun_test`에서 실행했습니다. 마이그레이션은 별도의 빈 시험 DB를 생성해 확인하고 제거했습니다. 처음 API 실행은 샌드박스가 로컬 TCP 연결을 차단하여 중단했고, 허용된 권한으로 다시 실행해 107개가 통과했습니다. 제품 오류를 수정해서 통과한 경우는 아닙니다.

프로젝트 루트에서:

```sh
npm run typecheck
npm run test:chat-stream
npm run test:mobile-chat
npm run build
.venv/bin/ruff check apps/api --select F,I
```

`apps/mobile`에서:

```sh
npx expo export --platform ios --platform android \
  --output-dir ../../.local/portfolio-validation-2026-10-15/expo-export
```

`apps/api`에서 전용 시험 DB를 사용해:

```sh
TEST_DATABASE_URL=postgresql+psycopg://yeoun:yeoun@127.0.0.1:54329/yeoun_test \
  ../../.venv/bin/python -m pytest -q

# 별도로 만든 빈 시험 DB를 DATABASE_URL로 지정한 뒤 실행
../../.venv/bin/python -m yeoun.migrate
../../.venv/bin/python -m alembic check
../../.venv/bin/python -m alembic current
```

원본 로그는 로컬 `.local/portfolio-validation-2026-10-15/`에 보존하며, [기계 판독용 결과와 로그 해시](validation-2026-10-15.json)를 함께 제공합니다. 해시는 해당 로그와 결과를 대조하는 수단이며 제3자 인증이 아닙니다.
