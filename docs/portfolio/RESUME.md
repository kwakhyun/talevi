# 테일비(Talevi) | AI 캐릭터 채팅 프로젝트

- 원본 대화와 모델 입력 문맥을 분리해 이름이나 취향 수정 시 무관한 약속까지 사라지던 기억 오류를 해결했습니다.
- 턴별 체크포인트로 답변 재생성, 메시지 편집과 분기 시 당시의 기억, 관계, 이야기 상태를 복원하고 원본 대화를 보존했습니다.
- 실제 모델의 합성 대화 평가에서 응답 1,256건을 완료하고, 30명 각각 30턴 대화 후 정정된 다섯 사실의 회상을 확인했습니다.
- 실제 PostgreSQL과 모의 모델로 상태 복원과 실패 처리를 검증해 API, 웹, React Native 자동 검사 144개를 통과했습니다.

**기술 스택:** Next.js, React Native/Expo, TypeScript, FastAPI, PostgreSQL, OpenAI API
