# 테일비 (Talevi) | 한국어 AI 캐릭터 채팅

2026.10 | AI 도구를 활용한 개발 프로젝트, 로컬 구현 및 검증

**기술:** Next.js, React Native/Expo, TypeScript, FastAPI, PostgreSQL, OpenAI API

30명의 캐릭터와 대화하며 사용자 기억, 관계와 이야기를 이어가는 웹과 앱을 개발했습니다. 캐릭터별 프롬프트부터 대화 상태 저장, 기억 편집, 답변 재생성과 이야기 분기까지 구현했습니다.

- **캐릭터별 대화 설계:** 말투, 감정 반응, 개인 과거와 관계 단계별 연기 지침을 프롬프트에 반영했습니다. 모델이 제안한 기억과 관계 변화는 실제 발언의 근거를 검사한 뒤 저장하도록 구성했습니다.
- **기억 수정 오류 해결:** 이름이나 취향을 바꾸면 무관한 약속까지 사라지던 문제를 수정했습니다. 원본 대화와 모델 입력 문맥을 분리하고, 변경한 사실만 가려 기존 사건을 유지하도록 했습니다. 사용자 기억의 수정, 잠금과 삭제도 지원합니다.
- **대화 분기와 상태 복원:** 턴 전후 체크포인트를 저장해 재생성, 메시지 편집, 분기 시 선택한 시점의 기억, 관계, 이야기와 설정을 복원했습니다. 새 대화에 맞게 근거 메시지 ID를 치환하고 원본 대화는 보존했습니다.
- **전송 실패와 중복 차감 처리:** PostgreSQL 작업 큐, 요청 멱등성과 크레딧 원장을 연결했습니다. 완성본 검수 후 SSE로 답변을 전달하고, 재연결 시 저장된 이벤트를 재생하며 실패한 작업은 앱 크레딧을 중복 없이 환급하도록 구현했습니다.
- **실제 모델 평가:** 2026-10-10 합성 대화 평가에서 완료 응답 1,256건을 기록했습니다. 이 중 30명 각각 30턴의 연속 대화에서 문맥 압축 후 정정된 이름, 음료, 약속 시간, 장소와 준비물을 전원 회상한 것을 확인했습니다.
- **자동 회귀 검증:** 2026-10-15 API 107개, 웹 11개, React Native 26개로 총 144개 검사를 통과했습니다. 실제 PostgreSQL과 모의 모델로 30명 전체의 분기 복원, 중복 요청과 실패 처리를 검사했으며 외부 HTTP 호출을 차단해 유료 모델 호출 없이 재현할 수 있도록 구성했습니다.

공개 배포 전 로컬 검증 단계입니다. 실제 모델 평가는 합성 대본 기준이며, 독립적인 이용자 평가와 모바일 실기기 및 실결제 검증은 수행하지 않았습니다.
