평가일은 **2026-10-10**, 문서 공개 준비일은 **2026-10-12**입니다. 이번 저장소 정리 과정에서 1,256건을 새로 실행한 것은 아닙니다. 최종 프롬프트 `ko-story-2026-10-10.11`에서 보존한 결과를 사용했습니다.

## 수정 전후에 확인한 차이

- 기억의 이름과 음료만 편집해도 기존 약속을 잃던 문제를 실제 API 흐름에서 재현하고 수정했습니다.
- 기본 응답은 개선 전 238/240 완료, 최종 버전 240/240 완료였습니다. 작은 합성 표본이며 운영 장애율 비교는 아닙니다.
- 개인 과거를 기록이 없다는 이유로 거절하던 3명의 사례를 포함해 최종 30명 모두 허구의 개인 과거에 답했습니다.
- 같은 “좋아하시는군요” 표현을 쓴 인물은 자기소개 30건 중 17명에서 5명으로 줄었습니다. 전체 말투의 독창성을 입증하는 점수는 아닙니다.
- 의미 없는 입력 85회로 신뢰가 오르던 규칙을 수정했습니다. 최종 규칙 검사에서는 전원 신뢰 0을 유지했습니다. 실제 모델 85턴의 연속 실험과는 구분합니다.

## 결과 해석의 한계

평가 도구가 817건의 후속 결과를 저장한 뒤 압축 모델 요청 한 건이 시간 초과로 끝났습니다. 앞선 결과를 보존하고 미완료 항목만 재개했습니다. 실제 워커에는 이미 압축 실패 시 최근 문맥으로 계속 응답하는 처리가 있었고 평가 도구에도 이를 적용했습니다. 재생성 초안, 압축과 검수 호출, 중단 당시의 미완료 요청은 1,256건과 별개입니다.

완료는 답변이 오류 없이 끝났다는 뜻입니다. Codex의 원문 검토는 독립적인 사람의 평가가 아닙니다. 관계 단계 비교에는 첫 만남과 깊은 신뢰 상태를 직접 넣었습니다. 30턴 기억 대본의 최종 단계는 전원 첫 만남이었으며 자연스럽게 깊은 관계까지 쌓은 실험이 아닙니다.

한국어 기억 표현 6건은 의미와 분류를 확인했습니다. 이 중 2건은 명사 대신 원문 구절을 저장해 엄격한 문자열 일치 검사는 4/6이었습니다. 표현 형식의 차이를 숨기거나 모든 검사가 동일한 자동 정답 조건을 통과했다고 설명하지 않습니다.

독립적인 사용자 평가자와 경쟁 서비스의 동일 조건 비교는 0건입니다. 몇 달에 걸친 기억, 운영 부하와 이용자의 재방문도 검증하지 않았습니다.

## 근거 자료의 공개 범위

[평가 요약 JSON](evaluation-summary.json)에 캐릭터별 수치와 원본 요약 파일의 SHA-256을 제공합니다. 해시는 공개한 수치의 출처를 대조하기 위한 것으로 제3자 인증이 아닙니다. 전체 합성 대화 원문, 코드 해시, 실행 로그와 재현 도구는 비공개 구현 저장소에 보존했습니다.
